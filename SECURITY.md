# Security Policy

## Reporting a Vulnerability

Este repositório contém documentação pública da plataforma EMBED. O código-fonte da plataforma está em repositório privado separado.

Se você identificar um problema de segurança relacionado à API ou à plataforma EMBED (como endpoint exposto, dado sensível na documentação, ou comportamento inesperado), por favor **não abra uma issue pública**.

Entre em contato diretamente:

- **E-mail:** comercial@embed.it
- **Site:** https://www.embed.it

Responderemos em até 5 dias úteis.

## Escopo

Este repositório cobre apenas documentação e scripts de integração públicos da EMBED Storage API. Vulnerabilidades na plataforma em si devem ser reportadas pelo canal acima.
